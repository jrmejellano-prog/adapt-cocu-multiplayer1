📜 Terms & Privacy

Terms of Use

Adapt CoCu is an educational game-based activity tool intended for Senior High School learners. It is a prototype for learning, practice, participation, and friendly competition.

Use the application respectfully. Game results, scores, XP, coins, achievements, and progress are provided for the application's learning and game features and are not official academic grades.

Privacy Policy

The application uses the name and section you enter to personalize the local game experience. Your game progress, scores, settings, achievements, coins, and customization can be stored locally on the device so the game can remember your progress.

This local version does not claim that your personal information is collected, sold, or shared with a server. Online multiplayer is different: room information and multiplayer game state are sent to the configured multiplayer server when you choose to use online multiplayer.

Teacher/Facilitator Progress Monitoring: Adapt CoCu can generate a compact progress summary from your local game data — your name, section, player code, level, XP, lesson and activity completion, accuracy, and achievements — so a teacher or facilitator can monitor learning progress. This summary is stored locally on this device and is only shared with a teacher if you export it, if a teacher imports it, or if the same online multiplayer server is reachable and a teacher's Progress Dashboard is used to retrieve it. It is separate from your personal History, which remains private on your own device. Teacher Dashboard access on a device requires a locally-set access code and is not accessible to other students.

If Offline Mode is enabled, the application continues using supported local features. Online multiplayer requires an internet connection and a working multiplayer server.

Your Choice

You may stop using the application at any time. You can also clear the application's local storage through your browser/device settings, which may remove locally saved game progress.

Educational prototype notice: Adapt CoCu is not a substitute for official school records, assessment systems, or professional advice.
